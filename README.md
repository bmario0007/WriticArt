# WriticArt — Atelier de Haute Papeterie & Calligraphie d'Exception

> *« Transformer les mots en œuvres »*

Site vitrine immersif, e-commerce et configurateur 3D pour la marque officielle **WriticArt** (Dakar, Sénégal).

---

## 🌟 Fonctionnalités Clés

1. **La Collection Writic’Love (365 Jours d'Amour)** :
   * Présentation des coffrets cultes : *Writic’Love Homme* (30 000 FCFA), *Writic’Love Femme* (30 000 FCFA) et *Le Duo d'Amour* (50 000 FCFA).
   * Commande instantanée en 1 clic via WhatsApp pré-rempli.

2. **L'Oracle Interactif « Une Carte Par Jour »** :
   * Tirage en 3D d'une carte d'inspiration quotidienne avec animation tactile et bruit de papier.
   * Partage de cartes et transfert vers le studio de commande.

3. **Studio 3D & Configurateur d'Atelier Sur-Mesure** :
   * Rendu physique 3D temps réel avec effet gyroscopique au curseur.
   * Bascule Carte / Enveloppe scellée avec sceau de cire 3D (matrice et couleur personnalisables).
   * Papiers nobles : *Coton pur bord frangé 350g, Parchemin vénitien patiné, Papier noir nuit minéral, Vélin blanc crème*.
   * Pigments minéraux & dorure à chaud en relief (effet *gold foil shimmer*).

4. **Galerie d'Art Officielle & Stories Instagram** :
   * Lecteur de Stories immersif en haut de page (*Writic’Love*, *Tableaux Réalisés*, *Cadres*, *Feedbacks*).
   * Inspecteur macro pour apprécier le grain du papier et le relief des plumes.
   * Bouton magique *« Commander dans ce style »* synchronisé avec le studio.

5. **Moteur de Devis & Bon de Commande Officiel** :
   * Chiffrage transparent en direct en **FCFA** (avec conversion indicative en EUR).
   * Génération de devis proforma numéroté, imprimable et prêt à l'export.
   * Envoi direct sur WhatsApp (`+221 77 234 85 21`) ou par email (`kaynubind@gmail.com`).

6. **Ambiance Sensorielle (Web Audio API)** :
   * Synthétiseur audio artisanal natif (froissement de papier, plume, sceau de cire, carillon).

## 🛠️ Stack Technique

* **Framework :** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Bundler & Build Tool :** [Vite 8](https://vite.dev/)
* **Styles :** [Tailwind CSS v4](https://tailwindcss.com/)
* **Typographie :** *Cormorant Garamond, Cinzel, Great Vibes, Pinyon Script, Alex Brush, Plus Jakarta Sans*
* **Icônes :** [Lucide React](https://lucide.dev/)
* **Effets :** Canvas Confetti, Web Audio API

## 🚀 Installation & Développement Local

```bash
# Cloner le dépôt
git clone https://github.com/bmario0007/WriticArt.git
cd WriticArt

# Installer les dépendances
npm install

# Démarrer le serveur de développement local
npm run dev
```
